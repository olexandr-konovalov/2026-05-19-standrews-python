# 2026-05-19-standrews-python

Notebooks for the Python part of the May 2026 Software Carpentry workshop in St Andrews.

- Workshop website: https://st-andrews-carpentries.github.io/2026-05-19-standrews/
- Lesson materials: https://swcarpentry.github.io/python-novice-gapminder/ 
- Data files: https://swcarpentry.github.io/python-novice-gapminder/files/python-novice-gapminder-data.zip 

Usage instructions: download lesson materials and unpack the archive in the project directory. 
You should get a `data` subdirectory with a collection of `.csv` files, required to run some of 
the notebooks to work with pandas and matplotlib libraries.

Examples are based on the Software Carpentries lesson "Plotting and Programming in Python".
